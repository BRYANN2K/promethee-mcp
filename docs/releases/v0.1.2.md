# Promethee MCP v0.1.2

A release-focused update for the local passwordless connection flow and installable GitHub archive.

![Promethee MCP local passwordless login page](https://raw.githubusercontent.com/BRYANN2K/promethee-mcp/v0.1.2/docs/assets/promethee-login.png)

## What changed

- Added the real local login page to the README and release notes.
- Added the missing `v0.1.1` session-reliability changes to the changelog.
- Made release SHA-256 files portable after download.
- Made the packed `npx` smoke-test use a cross-platform `file://` package URL.

## Install

```bash
npx -y \
  --package=https://github.com/BRYANN2K/promethee-mcp/releases/download/v0.1.2/promethee-mcp-0.1.2.tgz \
  -- prometheemcp
```

The installer can configure Codex, Claude Code, or print generic MCP JSON. Authentication stays in the browser on `127.0.0.1`; the email code and session tokens are never pasted into the AI conversation.

## Verify the archive

```bash
sha256sum -c promethee-mcp-0.1.2.tgz.sha256
```

Promethee MCP is unofficial and is not affiliated with or endorsed by Promethee. Live compatibility remains version-sensitive.
